# AI Agent Instructions

This directory is the complete recovery source for the project's remote Ubuntu server.
Assume the server can be suddenly lost and must be rebuilt from a clean machine.
Automate and document every required package, service, configuration, and deployment step.
Do not rely on undocumented manual changes, public internet access, or files stored only on the server.
Keep secrets out of Git and make automation safe to run repeatedly.
